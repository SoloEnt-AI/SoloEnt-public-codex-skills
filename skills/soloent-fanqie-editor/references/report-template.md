# 报告模板

按任务范围删减，替换所有占位项，不把模板指令输出进成稿。

```markdown
# 《书名》番茄诊断报告

## 总体判断与修改优先级
一句话概括最强卖点与最大阻碍。
- 目标频道：男频 / 女频 / 两者分别分析 / 待确认。
- 审阅材料：文件、版本与实际读到的范围。
- 本轮优先修改：1–3 项。

## 核心故事与市场匹配
- 一句话故事与读者承诺：
- 主要标签及语义契合证据：
- 市场查询事实与编辑判断：分别说明。
- 数据依据：SoloEnt MCP、实际 site、时间范围、查询日期；数据生成日期仅有返回时填写。数据缺失时说明局限。

## 五维诊断
| 维度 | 权重 | 分数或待评 | 具体文本证据与判断 |
| --- | --- | --- | --- |
| 平台适配 | 30% | | |
| 故事主线 | 15% | | |
| 前三章节奏 | 20% | | |
| 核心卖点与设定 | 25% | | |
| 文笔与代入感 | 10% | | |

按需要展开每项：具体章节或段落、短引文或准确转述、亮点、问题与修改方向。

## 修改清单
按优先级列位置、问题影响、可执行改法及修改后的验证办法。指出应保留的原作卖点。

## 结算与下一步
五项齐全时按统一权重计算一位小数总分，给本技能内部诊断档位；否则列待评项，不产生完整总分。建议先改什么、是否需补正文或重新核对定位。

本报告为 AI 辅助诊断，不代表平台官方签约决定、真实读者反馈或流量预测。
```

模拟读者体验仅在用户请求时另列，明确“AI 模拟”，不写成真实试读或调研结果。
